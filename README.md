🎬 영화 객관식 퀴즈 게임

# 1. 프로젝트 개요
Python을 이용한 영화 주제의 4지선다형 퀴즈 프로그램입니다.

# 2. 주제 및 선정 이유
- 주제: 영화 상식
- 선정 이유: 누구나 쉽게 즐길 수 있고, 객관식으로 구현하기에 적합한 데이터셋을 가지고 있기 때문입니다.

# 3. 실행 방법
```bash
python main.py

4. 기능 목록
퀴즈 풀기 및 점수 계산
새로운 퀴즈 추가 (파일 저장)
전체 퀴즈 목록 보기
최고 점수 기록 및 초기화
예외 상황(잘못된 입력, 파일 손상) 처리
5. 파일 구조 및 데이터 설명
main.py: 전체 게임 로직 및 클래스 정의
state.json: 퀴즈 데이터와 최고 점수를 저장하는 JSON 파일
quizzes: 문제, 선택지, 정답 번호 포함
best_score: 역대 최고 점수 저장
