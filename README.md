🎬 영화 퀴즈 게임 (Movie Quiz Game)

# 1. 프로젝트 개요
본 프로젝트는 파이썬의 객체지향 프로그래밍(OOP)을 활용하여 제작된 터미널 기반 영화 퀴즈 게임입니다. 사용자는 영화 관련 문제를 풀고, 점수를 기록하며, 데이터는 JSON 파일로 관리됩니다.

# 2. 퀴즈 주제와 선정 이유
- **주제:** 한국 천만 관객 영화 및 글로벌 명작 영화 퀴즈
- **선정 이유:** 
  1. 남녀노소 누구나 쉽게 접근할 수 있는 대중적인 주제입니다.
  2. 영화 제목, 명대사, 배우 등 다양한 형태의 퀴즈 구성이 가능하여 프로그램 확장성이 좋습니다.
  3. 학습자(본인)가 평소 영화에 관심이 많아 즐겁게 개발할 수 있습니다.

# 3. 실행 방법
1. Python 3.x 버전이 설치되어 있어야 합니다.
2. 터미널(또는 CMD)에서 프로젝트 폴더로 이동합니다.
3. 아래 명령어를 입력하여 게임을 실행합니다.
   ```bash
   python main.py

# 4. 기능 목록
퀴즈 출력 및 입력: 객체지향 설계를 통한 문제 출력 및 사용자 정답 입력 기능
점수 계산: 정답 여부에 따른 실시간 점수 합산
데이터 영속성: state.json 파일을 통한 퀴즈 데이터 로드 및 최고 점수 저장
예외 처리: 잘못된 입력값(숫자 외 입력 등)에 대한 방어 코드 적용

# 6. 데이터 파일 설명 (state.json)
경로: ./state.json (루트 폴더 내 위치)
역할: 퀴즈 문제 은행 관리 및 사용자의 최고 기록(High Score) 저장
스키마(Schema):
{
  "quizzes": [
    {
      "id": 1,
      "question": "문제 내용",
      "options": ["1번선택지", "2번선택지", "3번선택지", "4번선택지"],
      "answer": 2
    }
  ],
  "high_score": 0
}
