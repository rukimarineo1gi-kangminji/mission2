# **🎯 나만의 퀴즈 게임**

Python을 활용하여 제작한 콘솔 기반 퀴즈 게임입니다.
사용자가 직접 퀴즈를 풀고, 새로운 문제를 등록하며, 최고 점수를 확인할 수 있습니다.
Python의 기본 문법과 객체 지향 프로그래밍(OOP)을 학습하고, JSON 파일을 활용한 데이터 저장 및 Git을 통한 버전 관리 경험을 쌓기 위해 제작했습니다.

## 7. 데이터 저장 방식

프로그램에서 사용하는 퀴즈 데이터와 최고 점수는 프로젝트 루트에 있는 state.json 파일에 저장됩니다.

### 7-1. state.json의 역할
이 프로젝트는 프로그램이 종료되어도 데이터가 유지되도록 `state.json` 파일을 사용합니다.
 - **퀴즈 데이터 저장:** 등록된 모든 퀴즈 문제, 선택지, 정답 번호를 보관합니다.
 - **최고 점수 기록:** 사용자의 게임 최고 점수를 저장하여 동기부여를 제공합니다.
 - **데이터 복원:** 프로그램 재실행 시 저장된 JSON 파일을 읽어와 이전 상태를 그대로 복구합니다.

### 7-2. 데이터 구조 예시
파일은 아래와 같은 JSON 형식으로 구성되어 있습니다.

```
json
{
    "best_score": 40,
    "quizzes": [
        {
            "question": "봉준호 감독의 황금종려상 수상작은?",
            "choices": [
                "기생충",
                "괴물",
                "마더",
                "설국열차"
                        ],
            "answer": 1
        }
        // ... (중략) ...
    ]
}
```

### 7-3. 데이터 저장 규칙

 - 파일명: state.json
 - 저장 위치: 프로젝트 루트 디렉터리 (최상위 폴더)
 - 인코딩: UTF-8 (한글 깨짐 방지)
 - 데이터 형식: JSON (JavaScript Object Notation)
 - 세부 규칙:
    정답 번호(answer): 1~4 사이의 정수
    최고 점수(best_score): 정수형(Integer)
 - 예외 처리: 파일이 존재하지 않거나 손상된 경우, 프로그램 내부에 정의된 **기본 퀴즈 데이터**를 사용하여 자동으로 복구하도록 설계되었습니다.

## 9. 클래스 구성
본 프로그램은 데이터 모델(`Quiz`)과 게임 제어 로직(`QuizGame`)을 분리하여 유지보수가 용이하도록 설계되었습니다.

### 9-1. Quiz 클래스
개별 퀴즈 데이터를 관리하는 데이터 클래스입니다.

*   **속성(Attributes)**
    *   `question`: 퀴즈 문제 (문자열)
    *   `choices`: 4개의 선택지 (리스트)
    *   `answer`: 정답 번호 (정수, 1~4)
*   **주요 메서드**
    *   `to_dict()`: 객체 데이터를 JSON 저장이 가능한 딕셔너리(dict) 형태로 변환합니다.

### 9-2. QuizGame 클래스
게임의 전체 흐름 제어, 데이터 입출력, 사용자 인터페이스(UI)를 담당하는 클래스입니다.

*   **속성(Attributes)**
    *   `quizzes`: `Quiz` 객체들을 담은 리스트
    *   `best_score`: 역대 최고 점수
    *   `file_path`: 데이터 저장 파일 경로 (`state.json`)
    *   `default_data`: 파일이 없을 때 사용하는 기본 퀴즈 세트
*   **주요 메서드**
    *   `load_data()` / `save_data()`: `state.json` 파일에서 데이터를 읽어오거나 현재 상태를 저장합니다.
    *   `reset_to_default()`: 파일이 없거나 손상되었을 때 기본 데이터로 초기화합니다.
    *   `play_game()`: 퀴즈를 진행하고, 실시간 점수 계산 및 최고 점수 갱신 로직을 수행합니다.
    *   `add_quiz()`: 사용자로부터 입력을 받아 새로운 `Quiz` 객체를 생성하고 목록에 추가합니다.
    *   `show_quizzes()` / `show_best_score()`: 저장된 퀴즈 목록과 최고 점수를 화면에 출력합니다.
    *   `run()`: 메인 메뉴를 실행하고 사용자의 선택에 따라 각 기능을 호출하는 게임 루프입니다.

## 12. 프로젝트를 통해 배운 점
이번 프로젝트를 통해 다음과 같은 내용을 학습했습니다.

### 12-1. 어려웠던 점 및 해결 방법

*   **데이터의 영구 저장과 객체 변환:** 
    *   **문제:** 프로그램 종료 후에도 퀴즈와 점수가 유지되어야 했으며, JSON 파일의 딕셔너리 데이터를 다시 Python의 `Quiz` 객체로 변환하는 과정이 복잡했습니다.
    *   **해결:** `Quiz` 클래스 내부에 `to_dict()` 메서드를 구현하여 저장 로직을 단순화했고, 리스트 컴프리헨션을 활용해 JSON 데이터를 객체 리스트로 변환하는 로직을 구현했습니다.
*   **사용자 입력 예외 처리:**
    *   **문제:** 사용자가 숫자가 아닌 문자를 입력하거나, 선택지 범위(1-4)를 벗어나는 값을 입력할 때 프로그램이 종료되는 현상이 발생했습니다.
    *   **해결:** `while True` 루프와 조건문을 활용하여 올바른 값이 입력될 때까지 반복해서 입력을 받도록 예외 처리 로직을 강화했습니다.
*   **정답 비교 로직의 유연성:**
    *   **문제:** 초기에는 정답 비교 시 띄어쓰기나 대소문자 차이로 인해 정답이 오답 처리되는 경우가 있었습니다.
    *   **해결:** `.strip()`과 `.lower()` 등을 활용하여 사용자 입력값의 공백을 제거하고 형식을 통일함으로써 판정의 정확도를 높였습니다.

### 12-2. 새롭게 알게 된 내용

*   **객체 지향 프로그래밍(OOP):** 클래스를 통해 데이터(`Quiz`)와 기능(`QuizGame`)을 분리함으로써 코드가 훨씬 깔끔해지고 확장성이 좋아진다는 것을 체감했습니다.
*   **JSON 데이터 핸들링:** Python의 `json` 모듈을 사용하여 외부 파일과 데이터를 주고받는 방법과 데이터 직렬화(Serialization)의 개념을 익혔습니다.
*   **Git을 활용한 버전 관리:** 단순 저장이 아니라 `Feat`, `Fix`, `Refactor` 등 커밋 메시지 컨벤션을 지키며 작업 단위별로 기록하는 습관의 중요성을 배웠습니다.
*   **방어적 프로그래밍:** 파일이 없거나 데이터가 손상되었을 경우를 대비해 `try-except`와 기본값(`default_data`)을 설정하는 방어적 프로그래밍의 기초를 다졌습니다.
